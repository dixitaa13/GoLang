1. In go packages are used instead of class (and in this everything is derived from main package). there are no concepts like OOPs here 

2. Main function (main()) present in the file make the file executable and everything present inside it executed when we use the command "go run filename"

3. In golang every file present in a directory should redirect to a single package 

4. In go language if you have initialized a variable/function name with capital word then you can export it in other files but if it is initialized with small word then it will only be accessed in same file
